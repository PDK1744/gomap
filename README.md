# Gomap
## What is Gomap?
Gomap is an internal tool that we use at my current employer. It takes office layouts built with draw.io and creates an interactive layout in a dashboard. Then users can verify where assets are located in any of our many offices. Assets(PC, Printers, Phone Ext., ect) are able to be assigned to an office, room, or cubicle via drag and drop. In this projects current state there is a considerable amount of setup before there is a workable map in the dashboard. Current setup steps will be outlined further down. 

## Why was this created?

> **Note:** This project was built to solve a specific engineering challenge and isn't intended to be a one-size-fits-all solution for every environment. However, it could serve as a baseline that could be morphed to fit seamlessly into a specific infrastructure. The idea of turning this into a more adaptable project is not currently on my roadmap for this project. Unless I have the oppurtunity for collaboration.
> 
We currently have a internal inventory system for our assets. This inventory includes locations of all assets but it is based on the primary Users name. We do not have numbered offices or named rooms at any of our offices. Because of this the inventory tracks location of an asset by the User who uses the asset. For example if we have PC100 then location would be "Joe Dirt". If you have hundreds of employees then you may not know Joe Dirt and if you do, where is his office located? To ease this confusion is why I built Gomap. Now we can keep track of where devices are located in each office and easily relocate.
